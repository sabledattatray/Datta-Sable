# Phase 2 — public storefront

Implemented `/ebooks`, `/ebooks/category/[slug]`, `/ebooks/[slug]`, `/ebooks/library`, guest access and download views. Shared Navbar, Footer, fonts, theme variables and CSS modules are reused. Global eBook link is gated independently; Products remains available and cross-links the collection. Registered eBooks redirect from generic product URLs to their eBook canonical, and the generic catalog does not mislabel eBooks as test-only resource packages. The catalog has server-side published-only search/category filtering, deterministic sorting, 12-item pagination and actual category counts. No draft data, fake cover, reviews, discounts or unbundled files are inserted into the public UI.

Hero, factual commitments, optional featured grid, category browser, full collection, purchase steps, FAQ and existing policy links are present. Product view includes edition, author, format/pages/language/date, contents, outcomes, audience, prerequisites, included/excluded assets, licensing, updates and test purchase panel. Native details/summary provides keyboard-operable FAQs; forms have labels, focus styles and responsive layouts. Dark/light colors reuse site tokens; gold actions use dark text.

Actual screenshots: `screenshots/storefront-{320,375,768,1024,1440}.png`. They show the safe catalog-unavailable state because no configured DB connection was available. No invented product data was substituted. Library, guest access and admin authentication screenshots are also included. `browser-checks.json` records actual response status and overflow checks. Streamed Next.js errors may retain HTTP 200; the draft-product screenshot is an unavailable/error view, not evidence of a published book or a validated 404.

Remaining launch verification: upload the real cover and owner-approved PDF, publish in staging, capture the populated product/category/checkout/admin views at all requested widths, perform screen-reader/contrast checks and measure real Core Web Vitals. Separate sanitized preview PDF and scheduled publication are not implemented; no preview link is offered. The initial book remains a seedable DRAFT and is never used as public fallback.
